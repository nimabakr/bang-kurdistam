# Contributing

- Keep prayer calculations separate from UI and test calculation changes with
  fixed dates and city coordinates.
- Never label calculated or third-party schedules as official without an
  authoritative source, publication date and city coverage.
- Preserve coordinate attribution and ODbL attribution for OpenStreetMap data.
- Do not add location, notification, audio or widget UI that implies native
  behavior before that integration exists.
- Run `dart format .`, `flutter analyze` and `flutter test` before submitting.
- Do not commit credentials, signing files or user location data.
